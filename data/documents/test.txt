RAG（Retrieval-Augmented Generation）是一种结合检索和生成的大模型应用范式。它的核心思想是：先从知识库中检索出与问题相关的文档片段，再把这些片段作为上下文交给大模型生成回答。RAG 可以缓解大模型的幻觉问题，并让模型能回答私有领域的知识。

BM25 是一种基于概率的信息检索算法，全称 Best Matching 25。它通过词频（TF）和逆文档频率（IDF）对文档进行打分，擅长精确关键词匹配。BM25 的经典参数是 k1 和 b，k1 控制词频饱和度，b 控制文档长度归一化。

向量检索是指把文本编码成向量后，通过计算向量相似度找出相关文档的技术。它擅长语义匹配，但对精确关键词不敏感。常见的向量相似度度量有余弦相似度、欧氏距离、内积。

混合检索是指同时使用向量检索和 BM25 关键词检索，再通过 RRF（Reciprocal Rank Fusion）算法融合两路结果。RRF 的核心思想是不比较两路检索的分数，只根据排名融合。RRF 的公式是 score(d) = Σ 1 / (k + rank(d))，k 通常取 60。

重排序（Rerank）通常使用 Cross-Encoder 模型对候选文档做精细打分，把最相关的文档排到前面。Cross-Encoder 把 query 和 document 拼接后一起输入模型，比双塔模型精度高但速度慢，所以只能对少量候选做。

Chroma 是一个轻量级的向量数据库，支持本地持久化，适合中小规模 RAG 应用。它底层使用 SQLite 存储元数据，使用 HNSW 索引加速向量检索。

Milvus 是分布式向量数据库，支持水平扩展，适合大规模生产环境。它支持多种索引类型，包括 IVF、HNSW、DiskANN 等。

Faiss 是 Facebook 开源的向量检索库，性能高但不提供完整数据库功能，通常作为底层库被其他系统集成。

LangChain 是一个用于构建大模型应用的开源框架，支持文档加载、文本分割、向量化、检索、Agent 等能力。它提供了丰富的模块化组件，方便快速搭建 LLM 应用。

Embedding 模型是 RAG 系统的核心组件之一，负责把文本转成向量。常见的中文 Embedding 模型有 BGE、M3E、text-embedding-v3。BGE 是智源研究院开源的模型，在中文检索任务上表现优秀。

需要区分的是，BM25F 是 BM25 的扩展版本，用于多字段检索场景，并不是 BM25 本身。BM25+ 是对 BM25 的另一种改进，主要解决长文档的低频词问题。

向量检索中，余弦相似度衡量的是向量夹角，取值范围是 -1 到 1；欧氏距离衡量的是直线距离，取值范围是 0 到正无穷；内积没有归一化。三者对相似度的定义不同，余弦相似度对向量长度不敏感。

常见的向量索引包括：HNSW（分层可导航小世界图）、IVF（倒排文件索引）、PQ（乘积量化）、DiskANN（磁盘近似最近邻）。HNSW 适合内存充足、低延迟场景；IVF 适合大规模数据；PQ 适合内存受限场景。

常见的 RAG 框架有 LangChain、LlamaIndex、Haystack。LangChain 模块化程度高、社区活跃；LlamaIndex 专注数据索引和检索；Haystack 由 deepset 开发，适合生产级问答系统。

大模型幻觉有多种缓解方式，除了 RAG，还有提示工程、微调、知识图谱增强、约束解码等。RAG 的优点是成本低、更新快，缺点是依赖检索质量。

文本分块策略有固定长度分块、递归分块、语义分块、按文档结构分块。固定长度简单快速，递归分块保留语义边界，语义分块通过相似度判断切分点，按文档结构分块适合 Markdown、HTML。

评估 RAG 的指标包括：检索指标 Recall@K、MRR、NDCG@K；生成指标 BLEU、ROUGE、Faithfulness、Answer Relevance。检索指标评估检索质量，生成指标评估回答质量。
